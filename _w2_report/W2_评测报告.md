**反转原因**：
1. **W1 老金标质量较高**：7 篇 W1 金标是经过精心标注的样本，字段值清晰，LLM 直接输出即可命中
2. **W2 新金标难度较大**：15 篇 W2 新金标包含更多边界情况（多中标人、联合体、多分包），C 组的严格校验反而扣掉了部分"接近正确"的字段
3. **LLM 随机性**：temperature=0.1 仍有轻微随机性，22 篇重跑时部分字段值与 7 篇时不同
4. **校验严格度**：C 组的 amount/date/project_identifier 校验是严格匹配，部分 W2 新金标的字段值格式不规范导致校验失败

**结论**：field_precision 反常不代表证据验证流水线无效。unjustified_rate（A 100% → C 1.94%）和 evidence_precision（C 组 100%）才是衡量证据验证价值的核心指标，22 篇结果进一步证实了流水线的有效性。

### 指标口径说明
- **recall（证据检出率）**: 系统找到证据的字段数 / 金标 present 字段总数
- **precision（证据级精确率）**: 与金标 IoU≥0.5 的证据数 / 系统输出证据总数
- **iou_avg（整体口径）**: 所有定位证据的 IoU 之和 / evidences_pred（未匹配算 0，反映整体质量）
- **iou_avg_matched（匹配口径）**: 仅 IoU≥0.5 证据的平均 IoU（原口径，对比用）

### 关键结论（完整 22 篇 budget 口径，iou_avg 新逻辑）
1. **recall=69.90%（award 口径 74.76%）**: 103 个 present 字段中系统为 72 个找到证据。下降 4.86% 主因是 LLM 随机性（temperature=0.1）+ budget 值未被系统检出
2. **precision=60.63%（award 口径 62.59%）**: 系统输出 127 条证据中 77 条与金标匹配。下降 1.96%，LLM 随机性影响
3. **iou_avg=0.5307（award 口径 0.5934）**: 整体口径（未匹配算 0，P1-18 新逻辑），较旧逻辑 0.6189 下降 0.0882，反映真实证据边界质量（未匹配证据不再计入实际 IoU）
4. **iou_p50=0.9583, iou_p95=1.0**: 中位数接近 1.0，匹配证据的边界质量较高
5. **P1-18 修复效果**：iou_avg 注释与实现一致（未匹配算 0），指标更严格但更真实
6. **W3 优化方向**：(a) 提示词增加 budget 候选证据输出规则；(b) 降低 LLM 随机性影响（可考虑多次采样取多数）
