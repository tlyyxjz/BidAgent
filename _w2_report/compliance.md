# BidAgent 合规声明

本文件用于说明 BidAgent 项目在数据来源、隐私保护、AI 反幻觉、行业边界四个方面的合规情况，配套 W2 评测报告与 PPT 同口径数据。所有指标均来自 `_w2_report` 目录下的评测产物，口径一致。

- 版本：v1.0
- 发布日期：2026-07-28
- 适用范围：BidAgent 全部采集、抽取、报告生成与对外输出环节。

---

## 一、数据来源

- 招投标公告数据来源于中国政府采购网等官方公开平台，均为公开发布信息。
- 产品实际采集能力：**4+ 平台**（注意：行业背景中常出现的「数十平台」为行业整体数字，非本系统实际能力，特此切割说明）。
- 采集行为遵守目标站点 `robots.txt` 协议，请求频率限制为 **≤ 1 次 / 8 秒**，避免对源站造成压力。
- 遇 HTTP 403 立即停止抓取，**不切换 UA、不更换代理重试**（issue #34 已修复并固化此行为）。
- 公告内容版权归原作者 / 发布机构所有，本系统仅做信息聚合与字段抽取，不主张版权。
- 不绕过登录墙、不抓取付费内容、不存储原始 HTML 全文（仅保存抽取后的结构化字段）。

---

## 二、隐私保护

- 联系人电话 `contact_phone` / 邮箱 `contact_email` 使用 **SHA256 hex** 存储，不入库存明文。
- API key 使用 **SHA256 hash + `secrets.compare_digest`** 比对，防止时序攻击。
- 系统不收集用户个人身份信息（PII），不建立用户画像。
- 附件文件名做路径遍历净化（issue #13）：去除 `../` 与 Windows 非法字符，最终路径再校验是否落在 `ATTACHMENT_DIR` 之内。
- 所有外部 URL 请求前校验目标 IP，**拒绝私有 / 回环 / 链路本地地址**，防止 SSRF。
- 日志输出对电话 / 邮箱 / key 字段做脱敏处理，不打印明文。
- 数据库连接串、第三方密钥等敏感配置通过环境变量注入，不入库不入仓。

## 三、AI 反幻觉（风险提示）

- 报告输出明确标注「**AI 生成，仅供参考，决策请人工复核**」字样。
- 本系统定位为数据服务商，**不提供金融建议，不承担金融决策责任**。
- 证据验证流水线：无依据字段不展示，`unjustified_rate` 从 100% 降至 **1.94%**。
- 证据边界质量（22 篇金标，未匹配算 0 口径）：**IoU avg 0.5307**，P50 = 0.96 / P95 = 1.0。
- 字段精确率（C 组完整流水线）：`field_precision` **94.49%**，`evidence_precision` **100%**。
- 已知限制：`recall` **69.90%**（LLM 随机性 + budget 值未被系统检出），W3 将优化提示词补强。

### W2-08 消融实验（22 篇 budget 口径）

金标数量 22 篇（W1 7 篇 + W2 15 篇），金标口径为 budget + award 多值（K3 仲裁 B 口径）。

| 组别 | 配置 | unjustified_rate | field_precision |
| --- | --- | --- | --- |
| A 组 | 无证据 prompt | 100% | 93.70% |
| B 组 | 有证据不验证 | 0%（未验证，指标失真） | 93.70% |
| C 组 | 完整流水线 | 1.94% | 94.49% |

- 结论：`unjustified_rate` A→C 下降 **97 个百分点**，证据验证流水线可定位、可抑制无依据输出。
- 注意：**A = B < C**（B 组指标因未验证而失真，C 组才真正领先），证明只有「验证」环节才真正提升精确率。

## 四、金标数据限制与消融实验说明

### 4.1 金标数量限制

按 v4.1 总规划第十章 10.1 节，MVP 推荐 300～350 篇公告（开发集 130～140 + 校准集 80～100 + 测试集 100～110，≥70 个项目）。当前金标数量为 **22 篇**（W1 7 篇 + W2 15 篇，193 个证据偏移量全部人工验证），远低于 v4.1 目标。

**已知限制**：
- 22 篇金标无法支撑细分结论（按公告类型/行业/来源分层的统计效力不足）
- 未按 v4.1 要求划分开发集/校准集/测试集（当前为统一金标集）
- 未实现项目级 Bootstrap 置信区间（v4.1 第 10.10 节，W4 任务）
- 测试集项目数不足 70 个，统计效力受限，主指标仅作总体参考

### 4.2 D 组消融实验说明

v4.1 第 10.8 节定义四组消融实验（A/B/C/D），D 组为「完整 BidAgent（证据验证 + 来源处理 + 版本/冲突处理 + 选择性输出）」。

当前来源谱系、版本差异和事实冲突处理尚未实现（W3 任务），**D 组与 C 组配置等价（D=C）**，待 W3 完成来源谱系后补跑。

## 五、行业边界

- 本系统是招投标**信息聚合与字段抽取工具**，不是投资顾问。
- 不提供投标决策建议，**不承诺中标结果**。
- 信用评分基于公开中标数据计算，仅供供应商参考。
- 用户应自行核实信息准确性，**决策风险自负**。
- 系统输出不构成任何形式的要约或承诺，不作为合同或法律依据。
