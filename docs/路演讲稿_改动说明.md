## 二、路演讲稿改动

### 结构对比

| 旧版（ScrapeFlow） | 新版（BidAgent） |
|---|---|
| 命题：超聚变·招投标信息聚合工具 | 赛道：GOAI 2026 · AI+金融 |
| 五层架构 + 4 Agent 串行 | 六 Agent 协同闭环 |

| 亮点：SimHash 去重、反幻觉校验、PDF 解析 | 差异化：BOQ 报价异常 / 废标风险预警 / 供应商信用评分 |

### 关键改动点

1. **全稿清除 ScrapeFlow 字样**，队伍名"智汇标讯"→"标小智（徐浚钊、王祯明）"（与 PPT/清单一致）。
2. 定位句从"招投标信息聚合工具"改为"AI+金融 可验证招投标数据引擎"，并在总结部分明确与聚合工具切割（"不做信息搬运"）。v4.1 §9.1 已明确不输出信用评分，定位进一步对齐为可验证证据链引擎。
3. 3 个记忆点全部加粗并标注出现位置：
   - **"BidAgent 的每个数字，都能点回公告原文。"**（开场）
   - **"无依据输出，从 100% 压到 2.91%。"**（评测部分）
   - **"不做信息搬运，做可验证的信用评分。"**（总结）
4. 删除旧版无依据表述：53 测试、"综合评分 8.0/10"自评分、"等权 SimHash 准确率约 75%"等。
5. 新增 Q11（field_precision A>B>C 必问题）——直接引用评测报告 L119 的官方结论口径，预防评委翻评测报告时发难。
6. Q13 主动登记弱点（30 个 asyncio warning、覆盖率待补强），避免"571 全部通过"的绝对化表述（实际 571 passed + 1 skipped）。
7. 时间分配重排：开场 30s / 痛点 40s / 架构 60s / 差异化 70s / 评测 60s / 总结 40s = 300s。正文约 1300 字，按 4.3 字/秒配速 ≈ 300 秒，满足 5 分钟 ±15 秒。
