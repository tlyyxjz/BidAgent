## 九、常见问题

**Q1: 启动报错 `DEEPSEEK_API_KEY not configured`？**
A: 这是警告，不是错误。未配置 LLM 时自动降级到关键词解析，不影响运行。

**Q2: Word 报告中文字体乱码？**
A: 确保系统安装了宋体和黑体。Linux 上可能需要 `apt install fonts-wqy-zenhei`。

**Q3: 采集 ccgp 报错？**
A: ccgp 有反爬措施，频繁请求会被封 IP。建议配置代理池并控制请求频率 2-5 秒/次。

**Q4: 增量推送测试失败？**
A: 检查 `push_logs` 表是否有记录。如果订阅创建时无数据，第一次推送 count 可能为 0。
